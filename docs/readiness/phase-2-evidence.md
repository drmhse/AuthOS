# Phase 2 identity-security evidence index

Status: active readiness tracker  
Scope: Phase 2 of [`PRODUCTION_READINESS.md`](../../PRODUCTION_READINESS.md)  
Last source review: 2026-10-22

This is the canonical index for incomplete identity-security and protocol
evidence. `PROJECT_STATUS.md` states supported behavior,
`PRODUCTION_READINESS.md` defines the release gate, and the security architecture
and threat model describe current controls. Those documents link here instead
of maintaining competing backlog lists.

## Status and work classes

- **Done:** implemented and linked to repeatable evidence.
- **In progress:** implementation or repeatable evidence is incomplete.
- **Blocked by implementation:** qualification would be misleading until local
  behavior exists.
- **External qualification:** local fixtures may exist, but independent software,
  a release-candidate environment, or an assessor must produce the result.
- **Time-based:** evidence requires repeated successful operation over a stated
  period and cannot be completed by a one-time code change.

No row becomes **Done** from source review alone when its closure evidence calls
for runtime, interoperability, or independent results. Artifact links must name
the exact commit or image digest and the tested database/profile.

## Evidence hygiene

Evidence reports must contain:

1. The exact commit and, where applicable, container digest.
2. Database engine and version, topology, proxy assumptions, and configuration.
3. Protocol profile, client/peer implementation and version, sanitized fixtures,
   raw result location, summarized failures, and justified exclusions.
4. Test identifiers mapped to the relevant row above and to the
   [tenant-resource inventory](../security/tenant-resource-inventory.md) when
   authorization is involved.
5. Finding owner, severity, remediation state, due date, and retest link.

The matrix must be updated whenever a protocol claim, tenant resource, token
profile, cryptographic key, secret-storage path, or security-relevant outbound
integration changes.
